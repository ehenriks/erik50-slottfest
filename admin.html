Instruktioner & Hjälpguide

📄 Skapa & Koppla Google Doc (Tidsschema & Eventinfo)

Ett dynamiskt Google Doc för vad som sker när, tider, länk till anmälan och PIN-kod:

  1. Öppna malldokumentet eller skapa ett nytt i Google Docs.
  2. Klicka på Arkiv -> Skapa en kopia för att spara en egen version i din Google Drive.
  3. Uppdatera tider, program, länk till anmälningssidan samt PIN-kod.
  4. Klicka på Dela (Dela med andra) längst upp till höger och ställ in "Alla med länken kan visa".
  5. Kopiera länken och klistra in i fliken Inställningar under Google Doc Tidsschema Länk.

📊 Skapa & Koppla Google Slides (Bordsplacering & Utskrift)

Ett dynamiskt Google Slides-dokument för utskrift av bordsplacering (Sida 1 är översikt över festlokalen/borden):

  1. Öppna mall-presentationen: Öppna Bordsplacering Mall (Google Slides).
  2. Klicka på Arkiv -> Skapa en kopia -> Hela presentationen.
  3. Sida 1: Används för översikten av bordsplaceringen. Efterföljande sidor är bordskort för utskrift som uppdateras allt eftersom gästerna anmäler sig.
  4. Klicka på Dela -> Kopiera länk och klistra in under Google Slides Bordsplacering Länk i fliken Inställningar.

🗺️ Hämta Google Maps Embed Iframe & Länk

  1. Gå till maps.google.com och sök på festplatsen (t.ex. "Ljunglöfska Slottet").
  2. Klicka på Dela.
  3. För knapplänken: Kopiera den vanliga delningslänken (`https://maps.google.com/?q=...`).
  4. För den inbäddade kartan: Välj fliken Bädda in en karta, kopiera HTML-koden och ta endast webbadressen inuti `src="..."` (t.ex. `https://maps.google.com/maps?q=...&output=embed`).

🚀 Publicera på Google Cloud Run (Container)

Denna mall är förberedd med `Dockerfile` för snabb och billig drift på Google Cloud Run:

  1. Installera Google Cloud SDK (gcloud CLI).
  2. Ställ in ditt GCP-projekt: 
    gcloud config set project DITT-PROJECT-ID
  3. Bygg och deploya containern med ett enda kommando: 
    gcloud run deploy erik50-fest --source . --region europe-north1 --allow-unauthenticated
  4. Cloud Run ger dig en HTTPS-länk (t.ex. `https://erik50-fest-xyz.a.run.app`) redo att delas med gästerna!
